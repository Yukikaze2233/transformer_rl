# 独立评估轨迹的完整校验与重放

`exposure_trace.verify_trace_archive` 读取实际 NPZ 文件，校验每一个 NPY 成员，再按策略 tick 重放全部声明环境行的统计。调用方必须从已授权协议传入步数、环境行数、历史长度、动作限幅、稳态协议与预期元数据；文件中的自述维度和指标名称不能替代授权。

接口返回实际文件 SHA、大小及校验范围，以及总体和每个场景的 `control`、`history_control`。若协议同时声明 `evaluation_metric_names` 和 `evaluation_signal_names`，还会从原始 `eval_*` 样本重新计算 reward、任务指标、稳态波动、完成与失败回合数以及成功率。调用方应将这些重放结果与发布的 JSON 报告核对，不能只检查报告是否有限值。

## 原始样本及历史年龄

`pre_inference_episode_age` 为本次 actor 推理前、从 reset 开始经过的策略步数。首个输入年龄为零，完整历史条件为 `age >= history_length - 1`。终止步的物理样本属于该次旧回合，下一次推理才归零。重放逐行检查年龄、episode ID、上一 tick 的 `done`、物理时间和终止标志的一致性，H=1 的 reset-filled 类别保持零样本和空指标。

原始策略均值和下发动作分别保存为 `raw_policy_mean` 与 `issued_action`，后者必须等于按声明边界执行的 Torch clamp。腿部目标、轮速目标、PD 请求、缩放后的 nominal 请求以及实际物理力矩保持各自语义。可选 `command_request` 在控制统计重放时映射为 `request`；没有请求到达时间就不能推出传输延迟。

## 校验与资源范围

第一遍流式扫描会拒绝符号链接路径、未知或重复 ZIP 成员、非普通文件成员、加密或不支持的压缩、非 C-order 数组、对象/复数/结构化 dtype、非有限样本、非法布尔值、错误 shape、截断或额外载荷，并完整读取 ZIP CRC。第二遍按 tick 重放，保留原始浮点精度，跨 reset、历史类别或命令边缘的差分遵循统计模块定义。文件在校验前后还必须保持 inode、大小、时间及 SHA 一致。

解析器上限为 1,000,000 步、8,192 行以及 8 GiB 解压后成员总量；这些只是拒绝异常资源消耗的上限，不会扩大协议预算，也不证明磁盘容量足够。扫描与重放的内存按环境行数增长，不按评估步数保存全部轨迹。

这些检查证明发布报告可由被绑定的原始样本重现。checkpoint、训练阶段、冻结源码、运行时、环境资产、进程正常退出和锁租约由外层 provider/controller 另行核验。合成 CPU 测试不构成 Isaac 动力学、真实机器人传输时序或高频电流环的实测证明。
