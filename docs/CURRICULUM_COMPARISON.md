# Gated Transformer 课程对照

这组实验验证同一训练配方下，固定高度驻车预训练能否改善后续运动控制。它独立于正在运行的网络结构筛选，不修改原研究合同、检查点或训练队列。

## 三组与共同预算

| 组 | 更新 1–400 | 更新 401–1200 | 要回答的问题 |
|---|---|---|---|
| mixed | 原 V6 平地任务混采 | 同一任务混采 | 从头混合训练的基准 |
| stationary | 固定 0.305 m、零平移及转向指令 | 同一驻车任务 | 当前网络和奖励能否先学会驻车 |
| pretrain | 固定 0.305 m、零指令驻车 | 原 V6 平地任务混采，持续保留其驻车配额 | 先学习驻车是否改善最终控制 |

默认使用三个独立训练 seed：1101、1102、1103。每组每个 seed 从头初始化相同的 Gated 网络：31 帧 × 35D、128D、两层四头、FFN 512、动作头 256/128/6；critic、PPO、奖励、执行器响应、质量/接触/噪声/延迟分布保持一致。

纯驻车池没有起停任务，因此关闭原混合课程专用的起停随机计时器；这是任务采样设置的变化，传输延迟课程保持一致。

学习器先在 CPU 上按 seed 初始化，再创建任务环境，避免环境采样消耗全局随机数后改变初始权重。同 seed 三组的初始网络 tensor 内容 SHA 必须相同。

策略为 100 Hz，物理与新鲜反馈 PD 为 200 Hz。1024 个环境、48 步完整 rollout，每次更新 49,152 条实际样本。每个模型共 1,200 次更新、58,982,400 条样本，九项合计 530,841,600 条。KL 提前停止只改变实际优化工作；记录实际梯度步和优化样本曝光，不把它们当作新增环境样本。

三组均在第 400 次更新结束后保存、评估并重新创建环境和历史窗口。第二段保留模型权重、探索标准差、Adam 状态、学习器 RNG 和累计更新/样本计数。延迟课程仍按累计更新 200–600 增长，阶段切换不重新开始。第二段构造环境及首次 reset 也必须使用正确的累计时钟。

400 次是本次对照的固定分界，不代表驻车必然已经学会。第 400 次的独立评估用于判断是否确实获得了基础技能；只有获得后又退化，才讨论遗忘。

## 连续控制评估

两段终点都使用相同固定任务、扰动配置、独立评估 seed 和环境复制体。采用已冻结的 V6 测试集，分别给出名义条件与延迟、噪声、负载/质心、低摩擦、弱执行器等条件下的指标。评估结果不作为阻止下一段训练的门槛。

- 二维世界坐标速度模长的均值、RMS、P95，以及累计路径长度和相对 reset 原点的位移。差分严格在同一环境、同一回合内，不计 reset 跳变。
- 高度、前向速度、偏航角速度的绝对误差和有符号偏差，以及姿态倾斜。
- 去掉每回合前 200 步后的波动，按环境和回合分别去均值；同时记录有效窗口数量，缺少窗口记为不可用。
- 四个腿部目标与两个轮速目标的变化率、实际力矩与饱和比例。采用物理关节到动作关节的显式映射，不依赖 SDK 原始顺序。
- 实际训练样本、优化工作、耗时和跨训练 seed 的差异。

控制汇总覆盖每个声明的评估环境。轨迹与模型、配置、源代码及报告之间用 SHA 对应。二维差分速度是 100 Hz 采样指标；有限分辨率的 P95 必须标明估计方法，不能解释为下位机电流环抖动。

## 如何解释

纯驻车组优于混合组，说明单任务更容易，但同时改变了任务剂量，不能单独证明训练顺序是主因。预训练组与混合组的总预算一致，驻车样本剂量仍不同，因此结论是“驻车预训练方案的效果”，不能宣称已经隔离了纯顺序收益。

如果纯驻车也学不好，应继续检查奖励取舍、速度可观测性、探索动作与确定性动作的差异、执行链路和优化收敛。若驻车预训练已经获得良好控制、转入混合任务后退化，才有基础研究任务干扰或遗忘。

## 运行

先从已准备的 V6 transfer 配置创建新目录，原目录只读：

```bash
python -m transformer_rl.frame_cli prepare-curriculum \
  --base-config /absolute/path/to/prepared/base.json \
  --directory /absolute/path/to/curriculum_prepared \
  --warmup-updates 400 --updates 1200 --seeds 1101 1102 1103
```

独立控制器等待原架构实验的完成凭据与共享计算资源锁后串行运行，失败和部分运行保留证据，不修改冻结预算：

```bash
python tools/run_curriculum_campaign.py \
  --manifest /absolute/path/to/curriculum_prepared/manifest.json \
  --output-root /absolute/path/to/curriculum_campaign \
  --source-root /absolute/path/to/frozen_policy_source \
  --resource-lock /absolute/path/to/shared_resource.lock \
  --dependency-receipt /absolute/path/to/transfer_campaign/summary.json
```
