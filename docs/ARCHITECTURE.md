# 系统架构

## 代码边界

```text
transformer_rl/
├── formal/       正式运动控制实现
├── research/     网络对照、旧训练与实验协议
├── common/       数据类型、制品/RNG、进程控制和会话路由
└── *_cli.py      少量兼容命令入口
```

`formal` 与 `research` 不互相导入。两者只复用通用机制，不共享课程、模型配置或 checkpoint 格式。旧运行继续使用自己的冻结快照。

正式代码按职责分包：

| 模块 | 职责 |
|---|---|
| `formal/policy.py` | 结构化 Actor、独立 Critic、辅助头 |
| `formal/contracts.py` | 独立持有的观测、标签和动作顺序 |
| `formal/learning/` | 历史与 mask、采样、PPO、预算、checkpoint、更新循环 |
| `formal/control/` | 机械观测、输出轴控制、有效响应、气簧与几何边界 |
| `formal/tasks/` | 请求、命令、连续课程、地形、reward 与复位准备 |
| `formal/simulation/` | native 场景、读写桥、物理步、回合和任务适配 |
| `formal/runtime/` | 对象图组装、SDK worker、受控训练会话 |
| `formal/evaluation/` | 人工调用的评价计划、执行与结果 |

`policy` 不导入任务、控制或 SDK。物理与任务定义不依赖 PPO；学习器消费环境合同，不启动仿真。`runtime` 取得资源后组装对象。包的 `__init__` 不预先导入整套网络或环境。

## 维护与扩展

组装只放在 `runtime/assembly.py`，SDK应用寿命由 `runtime/worker.py`管理，资源和进程寿命由 `runtime/session.py`管理。算法、任务和控制对象通过构造参数取得依赖，不用全局注册表隐藏创建过程。

| 变化 | 主要修改位置 | 保持的边界 |
|---|---|---|
| 换网络或解码器 | `policy.py`、对应配置与检查 | 输入窗口和动作合同；不改仿真实现 |
| 改PPO或辅助损失 | `learning/optimization.py` | 采样、概率、标签与消费预算分别可核对 |
| 增加任务、reward或连续课程 | `tasks/` | 返回明确命令和物理条件；不导入学习器或SDK |
| 换机械资产、电机或传感器 | `control/`及对应native适配 | 通过命名绑定连接输出轴和物理量，不在网络里补传动逻辑 |
| 换仿真后端 | 新后端适配及runtime组装 | 对学习器提供相同的观测、完整转移、reset和控制权语义 |
| 加评价指标 | `evaluation/` | 人工单独调用，不耦入正式PPO循环 |

`contracts.py`是学习器和环境的数据交界：观测、标签、动作顺序与完整转移均显式传递，关键边界持有独立副本。通用类型、原子制品/RNG和文件控制机制留在 `common/`；只有会话路由和CLI允许按需选择正式或研究实现，其他通用模块不反向导入业务包。

这些依赖由 `tools/check_repository.py`静态检查。跨模块复用通过已有合同或通用机制完成；单模块内部逻辑先留在所属模块，不新增无明确职责的utility层。已有冻结训练快照与新源码版本分别维护。

### Isaac Lab 接入

`lab_env/sdk.py`集中处理应用寿命与设置接口。GA使用公开的`launch_simulation`，明确选择Kit PhysX；beta保留自己的启动路径。GA在`cfg.scene`声明机器人，共享地形和接触视图由环境接线。`ga_isolation.py`通过机器人资产的公开`cloning_contexts`登记同构Env ID，保留共享地面的碰撞组回读与原PhysX manager，不修改安装的SDK或全局回调。

物理边界统一使用`xyzw`四元数、世界系COM线/角速度；观测组装器再换算link原点速度与机体系分量。reset仍执行写后FK刷新；需要跨越reset的终态必须持有副本。GA的质量、COM和惯量随机化使用公开setter同步缓存，保留原采样参数与RNG。我们的200Hz控制器继续独立计算电机力矩，显式关闭GA新增的host actuator执行路径。

根姿态与COM主轴姿态不是同一个量。`get_coms()`的旋转表示惯量主轴相对刚体的方向，写入惯量后可能重新选择；惯量矩阵则在COM处、以刚体prim坐标系表达。跨SDK迁移分别核对质量、COM位置和完整惯量矩阵，保留两份原始身份及验证收据；不能仅凭四元数字节不同判定物理变化，也不能改写旧记录来通过恢复。

升级SDK不替换PPO、mask、课程或journal，也不自动继承旧SDK的物理与性能资格。RSL-RL可作为独立后端研究接口；其优化器、KL和timeout语义不同，不能直接替换现有学习器并称为无损迁移。

## 网络接口

正式路径使用单一Actor：100Hz、五帧含当前、35D观测和6维动作。独立185D Critic由182D环境物理量与3D停止梯度的估计速度拼成。网络层次、输入分组、历史mask、参数量与部署裁剪集中在[网络架构](NETWORK.md)。

## 采样与更新

```text
200Hz物理/反馈 → 100Hz观测与请求 → 完整rollout
 → 冻结旧策略概率与原始窗口 → 当前权重重算 → 独立PPO更新
 → 完整更新边界 checkpoint / 暂停 / 保存退出
```

正式配置集中在 [`configs/formal_training.json`](../configs/formal_training.json)，由 `formal/learning/settings.py` 展开为完整recipe；运行层再绑定资产、源码、初始权重与SDK。修改配置只影响新冻结会话，已有会话的预算和恢复状态不会被改写。

每轮8192环境×48步，共393,216个环境转移，每个环境覆盖0.48秒。PPO为4 epochs×16个逻辑minibatch，每批24,576个端点；Actor按最多3072端点分块累积梯度，再统一裁剪和更新。PPO按整批样本数归一化，各辅助项按整批有效标签数归一化，避免不均匀mask改变权重。Actor与Critic各自最多64次Adam更新，KL回滚包含整个Actor及辅助更新。

采样规模、100Hz和五帧历史对齐复旦[`plane`默认配置](https://github.com/yly-true/fudan_rl_wheel_leg/blob/8204e853dfd2ed06d85a322e1a998c3d20a3be2c/plane/wheel_legged_gym/envs/base/legged_robot_config.py)。其MLP优化参数并非本Transformer的整套配置：

| 设置 | 本正式配置 | 选择依据 |
|---|---|---|
| 环境 / rollout / 历史 | 8192 / 48 / 5帧含当前 | 对齐复旦plane，保持0.48秒rollout |
| epochs / 逻辑minibatches | 4 / 16，前后向分块3072 | 控制激活显存；不增加逻辑Adam步数 |
| 学习率 / clip / 熵系数 | 固定1e-4 / 0.2 / 0.005 | 保留本优化器设置；与v7初始值一致 |
| value系数 / 梯度范数上限 | 4 / 1 | 保留v7基准值，Critic独立优化 |
| gamma / GAE lambda | √0.99 / √0.95 | 保持v7从50Hz换至100Hz后的时间尺度 |
| 周期checkpoint | 每100更新；暂停/停止另存 | 减少常规写盘，启停仍保存完整状态 |

每seed完整四段为35,000更新，3个seed合计41,287,680,000条fresh转移。预算按实际reservation扣除，中断和丢失的学习状态不退款；保留的模型更新号与已消耗预算号可以不同。原生地形、显存和吞吐资格属于具体SDK与冻结来源，不随配置或代码迁移自动继承。

- 概率比：`r = exp(logπ_new − logπ_old)`。
- 策略损失：`−mean(min(rA, clip(r, 1−ε, 1+ε)A))`。

`A`为有效策略样本的归一化优势，`ε`为clip比例。历史mask、actor/辅助标签mask、GAE传播与value bootstrap分别处理，不把脚本接管的结果归给策略。

课程按连续训练曝光推进，不等待自动评价或通过率晋级。人工评价独立于PPO循环；评价结果不冒充训练重复或真实部署资格。

粗糙地形的源高度场位于 `tasks/roughness.py`：由全局坐标索引和geometry seed确定各顶点，保留完整请求域、0.25m间距、入场/离场过渡和同一三角对角线。`simulation/terrain_stream.py`按需铺设8×8网格单元的块；共边顶点一致，分块次序不消耗RNG。完整源和课程身份独立于驻留块，不把附近小块当作完整任务域。

流式铺设在完整策略边界进行：由真实身体位姿、源碰撞包络和当前运动保护近身块，保留其原碰撞prim，只新增/退休远端块。零物理步编辑后交接地面查询与接触视图，不reset机器人、时钟、历史或预算。Kaiser小场景已运行过原生新增/退休与后续PPO路径；这不证明隐藏求解缓存完全等价，也不代替8192环境的显存、长程边界和吞吐实测。平地复用同一分块机制，每块四个共面顶点，完整最长行程由共享零高度源保留；不会在每个环境重复放置覆盖全部行程的大AABB。普通/扩展任务的30s/60s时限保持独立。

PhysX的GPU配对缓冲在创建场景时显式配置并回读。`simulation/health.py`接收当前SDK的物理错误；异步回调只记录错误，采样线程在原生步返回后、发布观测前拒绝受损区间，禁止重放。正常的PPO返回值不能替代物理错误检查。

`simulation/materials.py`按精确摩擦系数复用物理材料，不将连续参数量化成固定档位。碰撞体退休时减少引用，最后一个引用移除后释放材料，避免流式课程累计耗尽SDK材料槽。平地初始仅驻留一块4×4m的双三角形，后续沿同一完整源扩展；机器人之间仍按环境碰撞组隔离。

回合reset的新课程若使用同一完整地形源，且当前驻留块已覆盖新的出生足迹，就复用当前面，避免先拆成初始小面再扩展。请求、geometry seed、课程摘要和RNG照常推进；源不同或出生区未覆盖时仍走原生替换。该优化不改变已冻结运行，吞吐收益以Kaiser实测为准。

驻留边界来自CPU几何元数据，按整批构造后一次上传；不逐环境写GPU标量。完整域边缘和提前1m补块规则保持不变。

## 物理与恢复

控制链为“网络位置／轮速目标 → 同部署反馈控制 → 录包辨识响应 → 闭链、气簧与接触动力学”。当前腿反馈为`160(q_target−q)−2.5dq`，轮速反馈为`0.6(omega_target−omega)`；力矩上限为四腿40N·m、两轮4.5N·m，再按实际降额处理。PD属于控制器，辨识参数用于还原实际响应，两者不由网络层定义。Critic的特征缩放只改变输入数值表示，不缩放真实力矩或辨识曲线。

策略50Hz、物理200Hz，闭链求解固定position12 / velocity6；1kHz只作独立数值参考。请求发出、传输到达、控制应用与物理响应分别计时。电机拟合的有效响应只应用一次，不叠加重复的USB时延。

DirectGPU模式下，CPU场景射线不保证跟随动态GPU位姿。轮形状射线只在显式物理推进前核对初始cook；运行中的净空仍使用GPU位姿与已绑定的源几何。静态地形替换另核对新增/退休碰撞路径、实际articulation根路径和零物理步，不把可见状态不变当作隐藏求解缓存等价。

Actor的传感器模型位于 `control/sensors.py`：200Hz缓存四组具名读数，50Hz选择过去样本后加入物理单位均匀噪声；原始样本时刻随读数保留，reset行清缓存。正式preset（`configs/control_timing.json`）对齐华南虎：每回合整条观测共用一个5/10/15ms延迟，航向以cos/sin通道随IMU组同延迟，航向外环只读该延迟值。回合抽样与观测噪声使用独立RNG，部分reset保留继续行的当前读数和后续噪声流。

目标传输只保留一个模型：`lab_env/action_transport.py` 的子步锁存让新目标晚1–2个物理步生效（5–10ms），部分reset只改写对应行；配置拒绝与整策略步传输延迟同时启用，`lab_setup.json` 写出合成后的总延迟分布。轮电机按M3508＋15.62减速的力矩-转速包络（堵转30.2N·m、空载62rad/s）限幅，腿保持理想PD。

可选的 `control/communication.py` 统一分配每回合往返延迟；正式preset为上行0.1–2ms、下行0（下行由子步锁存表示），属于工程先验。PD和Actor共用上行预算；PD用相邻真实物理读数插值，Actor再叠加自身的整物理步观测延迟和噪声。下行把一个5ms区间分为旧、新PD力矩两段，分别调用原辨识响应积分，再以总冲量除5ms得到仿真平均力矩；没有额外物理子步。Critic及监督真值保持干净。记录发出、到达、PD计算和应用来源年龄；响应端点与区间平均力矩分开。控制权交接清空对应行的旧力矩，不重放脚本包。

可选 `episode_randomization` 以累计更新数确定平滑曝光，在新回合展开观测噪声、往返预算、气簧0.9–1.1倍强度、腿/轮强度降额0.8–1.0/0.9–1.0、腿编码器零位±2°（Critic可见）、轮空载转速0.92–1.05倍、腿响应时间常数1–2.5倍，以及每5–10s的±0.25m/s推扰和±10N/±1N·m机身外力，默认5000更新到完整范围。它不改变阶段权重、不在回合中途改参数，也不重新抽取启动质量/COM或轮材质。冷恢复保留独立RNG及消费计数，重建物理历史；新增时序状态必须完整绑定，不能把旧快照直接当作新链路接续。该路径不表示通信辨识或实机资格已完成。

启动动力学参数位于 `simulation/dynamics.py`，配置由 `runtime.tuning.dynamics`冻结。首个物理步前，按具名刚体与固定seed抽样：机身质量0.9–1.3倍，其他连杆0.9–1.1倍，机身COM偏移不超过±(4,2,2)cm，20%环境保留标称值。每根刚体惯量随其质量同比缩放，不另加独立惯量扰动；不改变连杆、关节轴、所选机械止挡或电机整链响应。正式训练改用107°膝止挡资产`stop107_reference_v2`（膝内角40–107°，与105°版本仅被动膝限位不同），编码器零位由回合随机化覆盖±2°。写入后核对原生质量、COM、惯量，再刷新观测模型；reset和reward随后读取实际每环境参数。相同seed冷启动重建同一组机械参数，回合reset不重复抽样。原生写入与回读已在Kaiser检查；范围仍是工程先验，不代表完整Sim2Real随机化或物理验收通过。

可选runtime段（时序、材质、锁存、电机包络、命令池、出生）的解析集中在 `lab_env/sections.py`，不导入仿真器，entry预检、managed runtime、诊断训练器和checkpoint评价共用；静态课程的env与PhysX配置由 `lab_env/cfg.py` 的 `build_course_env_cfg` / `configure_course_physics` 统一生成。出生与终止计数由env自身的 `episode_diagnostics()` 发布，课程指标只含课程状态。

出生与台阶请求各自独立成模块：`lab_env/birth.py` 在CPU上一次求解并认证闭链腿姿库（腿长按膝止挡均匀、腿角在策略可保持的输出域内均匀），reset时只做索引；地面出生由 `lab_env/recovery.py` 的释放区间输出零力矩0.2s，所有权记为脚本控制。`lab_env/stair_trigger.py` 只消费沿行进方向的高度剖面，实机ToF读数可驱动同一检测逻辑。`tasks/command_pool.py` 抽取回合内命令段，`tasks/termination.py` 对倾角、低高度与机身接触做0.4s持续判定，非有限状态与闭链损坏仍立即终止。

checkpoint保存模型、Adam、RNG、课程和消费预算。暂停在完整更新边界保存并留在同进程；保存退出后的冷恢复保留学习状态，但重建物理回合与历史。它不保证断电且无checkpoint时恢复未保存状态。

经明确批准的性能源码切换由 `runtime/transition.py` 执行：原parent正常退出后，先用原recipe与journal严格接受最终快照；新会话保留全部学习张量和RNG，逐字继承事件链，以独立来源记录绑定旧/新identity及非零预算。仅源码摘要、journal identity和迁移元数据变化；普通resume验收不放宽，未封存的迁移会话不能退回从零初始化。切换仍需原资源准入，物理回合按既有冷恢复规则处理。

失败事务后的旧检查点不属于普通resume。经明确授权的私有恢复由 `runtime/recovery.py` 创建独立分支：先核验只读证据缓存和完整hash链，在检查点对应的精确事件前缀上执行原快照验收；新journal首事件显式继承全部已占预算，并分别保存保留模型的计数和已丢失的历史执行消耗。只推进课程的已消费额度，不伪造模型、Adam、RNG或请求状态；它们仍来自最后有效检查点。新日志和面板分别显示模型更新数、预算进度和全历史执行量。原失败journal保持失败且禁止普通resume；恢复分支也不能回退到fresh初始化。冷恢复仍重建物理回合与历史，不声称恢复了丢失更新的学习状态。

SDK迁移还需封存并实测解释器、源码提交、锁文件、包版本与必需库路径，随后保持普通冷恢复的精确机械身份检查。原生失败时先发布原异常，将环境和应用上下文保留至worker显式非零退出，防止SDK关闭或生成器回收把失败变成`exit(0)`；成功路径正常释放资源。

每轮日志分别记录采样、优化和预算/checkpoint耗时，采样内再区分地形、物理、地面查询与reset。分项为主机墙钟，不额外插入逐物理步CUDA同步；嵌套分项不能重复加到完整耗时，阶段名称也不代替GPU kernel归因。

网络、资产、控制参数、SDK和时序分别绑定来源。代码和静态检查不能代替原生碰撞、闭链、任务可达域或Sim2Real验收。
