本次另写纯 CPU 分析：取 `kinematics.json` 的实测轴心，直接用 `scipy.optimize.root` 同时求解 BE 与 AD 两个平方杆长约束，得到 C3 转角 α、C0 转角 β；检查上分支 +1、下分支 −1，再以两孔刚体映射构造 C1/C4。求解器未调用旧两次交圆实现，随后独立与 USD 实际变换比较。

## 4. 几何支持的两级拓扑与运动比

以 C2 为固定参照：

- 下四杆：`O–A–D–P–O`，组成是 C0、C1、C3 下臂、C2。
- 上四杆：`P–B–E–K–P`，组成是 C3 上臂、C4、shank、C2。
- C3 的 P/B/D 是**同一个三孔刚体**，两个回路共用 C2/C3。

本次从轴坐标重新计算名义长度：`OP≈OA≈113.4 mm`、`AD≈PD≈135 mm`、`PK≈BE≈96.6 mm`、`PB≈KE≈67 mm`。详细左右非取整值在 JSON 的 `independent_poses.*.*.lengths_mm`。

对理想平面、转动副、普通位形假设，每侧机构含地杆共有 6 bodies、7 revolute connections、2 个独立回路，机动度 `3×(6−1)−2×7=1`。加上髋和轮，每侧仍可用 3 个宏观广义坐标；加双侧和基座是 **15-body 候选物理分解、6 个内部广义坐标**，另有自由基座运动。不能把视觉节点数量或 7 个销轴当作独立驱动数量。

## 7. 最小后续路径：需要先明确的真实取舍

### 路径 A：按 15-body 候选分解建立正确闭环动力学

适合要保留实际内部构件运动、惯性、约束力和传动耦合的目标。下一步首先补齐：

1. **机械／执行器连接表**：15 个运动分组是否对应实际刚体，O/A/D/P/B/E/K 的 mate、轴向锁定与轴承层叠、O 处 base/C2/C0 连接、主动／被动轴、链轮和编码器参考。几何已有候选图，驱动归属仍需机械确认。
2. **按真实刚体分组的 mass/COM/完整惯量及 frame**，含电机转子反射惯量、轴承／紧固件归属；复核总质量与惯量一致性，避免旧 aggregate 重复分配。
3. **接触／执行器物理信息**：碰撞近似与允许接触对、轮胎滚动半径／摩擦、止挡、关节摩擦／阻尼、间隙／柔顺、控制模式、增益、速度力矩包络和传感器延迟。

之后才能在独立派生资产中实现合适的物理树和闭环约束。几何候选图有每侧 7 个机构转动连接，再加 hip/wheel；双侧合计 18 个连接、4 个独立回路。这是建模参考，**当前 USD 内一个物理 joint 都没有**。具体后端的闭环表示、树边选择／非树约束、初始化位置速度一致性和数值稳定性必须单独验证，不能只给全部 Xform 加 RigidBody API。

### 路径 B：用户明确接受的简化等效串联模型

适合优先研究宏观 hip–knee–wheel 控制、允许近似内部动力学。最少需要确认：

1. **等效范围**：哪些内部运动质量、接触、间隙／弹性效应被保留或省略，目标工况与误差接受范围；是否仅把新闭环几何作为跟随宏观 q 的视觉层。
2. **可信等效动力学依据**：由经确认的组件参数推导，或以实测辨识宏观惯性／重力／驱动响应。约束消元一般给出随姿态变化的 `M_red(q)=J_body(q)^T M_body(q) J_body(q)` 及相应偏置项；不能保证旧 7-body 的固定 lumped inertia 精确等价。
3. **真实主动轴映射与反馈**：若要对应实机，仍须确认电机／链传动／encoder；若阶段性直接驱动广义坐标，需明确其为理想化研究假设及执行能力界限。
