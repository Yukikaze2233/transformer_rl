# 网络结构的闭环运动控制评估

模型选型先检查任务是否达标，再比较动态响应、执行器负担和实时开销。训练 reward 与普通持续任务的存活率不能替代指令跟踪成绩。本协议独立于训练计划，使用相同冻结检查点、场景和评估 seed 比较单帧 MLP、历史 MLP 与 Transformer。

## 评估信号与口径

`--control-output` 启用额外的 PRE-reset 物理诊断，默认不影响既有训练与评估。按场景分别输出：

- 高度、前向速度和偏航角速度误差：bias、MAE、RMSE、峰值、误差带内样本和时间比例、全区间 IAE。稳态按每个环境的每个固定指令保持段去均值，同时保留各段均值差异。
- reset 与指令切换分别计数。失败和短回合计入全区间统计；稳态样本不足时明确标记，不能以丢弃短失败回合得到的低波动作为成功证据。
- 大幅有效指令切换：采样点上的 10%–90% 上升时间、绝对超调、进入容差并连续保持 0.5 s 的调节时间。初始指令未跟踪、保持时间过短、终止或未到达目标分别标记；无法确定的指标为 null。持续小幅 slew 不冒充阶跃。
- 腿目标变化率 rad/s、轮速目标加速度 rad/s²、连续腿关节最短角差、轮速目标到实际速度的误差、实际力矩 RMS/峰值与变化率、请求力矩超限和实际力矩到界比例。
- 采样点上的绝对机械功率 \(\sum_j|\tau_j\dot q_j|\)，不称为电耗或高频电流纹波。实际力矩与请求力矩分别记录。

初筛误差带沿用现有场景：速度 0.15 m/s、偏航速度 0.25 rad/s、高度 0.03 m。它们是仿真初筛参数，不是硬件验收标准。每段保留充分样本后再比较波动；跨 reset 不作差分或误差积分。位移只有在静止指令下解释为漂移。

## 原始轨迹

`--trace-output` 保存可复查 NPZ，默认按每个场景预先选定前两个副本，不按成败选择轨迹。完整场景统计仍使用全部环境。数组包括有效指令、实际响应、目标与实际执行器量、时间、done 和 episode_id；元数据保存检查点 SHA、seed、观测/动作合同与采样频率。

轨迹使用磁盘映射写入，内存不随评测时长增长；完整成功后发布最终文件，失败保留日志而不发布完整轨迹。100 Hz 轨迹只覆盖策略采样频段，不能代表 1000 Hz 物理子步的全部峰值。没有可靠的请求时间戳时不报告传输时延。

执行器数组统一采用四个腿关节、两个轮关节的顺序；位置、速度、实际与请求力矩、力矩边界使用同一映射，关节名称随元数据保存。物理关节位置和速度在环境步结束后、reset 前从仿真状态读取，避免将控制器延迟反馈当作实际响应。

## 独立补充评测调度

```bash
python tools/run_frame_control_campaign.py \
  --study-root STUDY --output-root OUTPUT --source-root SOURCE \
  --updates 200 --seeds 5701 6701 --steps 4001 --device cuda:0
```

调度器核验原计划、配置、训练完成回执与检查点 SHA；等待原执行器释放锁并确认原 worker 已结束，然后串行评测全部十种候选。原任务门槛不通过的模型仍保留在补充评测中；未到预算的模型明确列为未就绪。每次失败后创建新 attempt，完整产物不覆盖。新增评估 seed 与原训练、验证、锚点和最终测试 seed 分开；新增结果用于补充验证，不冒充未接触过的最终留出测试。

`campaign.json` 固定源代码、场景、预算和 seed；`summary.json` 记录运行状态及所有候选；每个 attempt 保存命令、进程身份、场景报告、control.json、trace.npz 和 SHA 回执。统计按场景、评估 seed、训练 seed 分层汇总，不能把帧数当作独立训练 seed 数。

先完成相同预算的固定场景评估，依据任务达标与控制指标筛选候选，再对合格候选执行抗扰、时延扫描、历史长度消融与跨课程技能保持验证。额外实验需要冻结各自场景协议和来源；本套件不将它们标作已经完成。


## 遗忘、学习率与记忆分析

网络选型增加两条独立证据：新技能能否学会，以及学习新技能后旧技能是否保持。时序历史解决单次控制中的信息不足；旧技能保持解决参数更新后的行为退步。增加 Transformer 历史长度或参数量，不自动保证抗遗忘。

把旧任务 A 与新任务 B 的局部损失分别记为 \(\mathcal L_A,\mathcal L_B\)，普通梯度更新的一阶近似为

\[
\Delta\mathcal L_A\approx-\alpha\,
\nabla\mathcal L_A^\top\nabla\mathcal L_B.
\]

当两个梯度方向冲突时，学习 B 会提高 A 的局部损失。Adam 则需将新任务梯度替换为实际预条件更新方向。这说明结构、学习率与任务混合共同影响行为保持；局部梯度干扰只能作诊断，最终仍需闭环复测判断旧技能是否退步。

### 旧技能遗忘与保持率

固定技能列和评估协议，每个课程检查点对应一行。技能可以包括站立、前后运动、旋转、换高、启停、坡面和抗扰；行是实际检查点，而不是每次 reset。每个单元保存任务完成、跟踪误差、漂移、动态响应、力矩与饱和情况。相同技能在不同时刻使用相同场景、评估 seed、扰动协议和控制门限。

令 \(Q_{t,j}\) 为检查点 \(t\) 对技能 \(j\) 的任务与控制联合达标率，约定越大越好：

\[
F_{t,j}=\max_{k<t}Q_{k,j}-Q_{t,j},\qquad
F^+_{t,j}=\max(0,F_{t,j}).
\]

保留有符号退步量以观察正迁移，另报告非负遗忘。后向迁移为

\[
\operatorname{BWT}_t=\frac{1}{|\mathcal J_t|}
\sum_{j\in\mathcal J_t}\left(Q_{t,j}-Q_{c_j,j}\right),
\]

其中 \(c_j\) 是技能首次训练结束的检查点，\(\mathcal J_t\) 是此前引入的技能集合，参考值必须来自同一评测协议；一个课程可引入多个技能。缺失复测或空集合时不填 0。这个矩阵思路来自持续学习评价；运动控制中的联合达标定义需要按本项目场景另行冻结。[GEM 原论文](https://arxiv.org/abs/1706.08840)

工程上再报告旧技能保持率：

\[
R_t=\frac{\#\{\text{此前已掌握且当前仍达标的技能}\}}
{\#\{\text{此前已掌握的技能}\}}.
\]

“已掌握”必须先通过固定验收门限；从未学会的技能不计为遗忘。没有已掌握旧技能时 \(R_t\) 为不可定义，不能填 100%。保持率之外仍展示连续误差，避免门限掩盖退步。单纯存活的 `success_rate` 不直接等于 \(Q\)，需联合跟踪和控制要求。

实验从同一个合格 A 技能检查点分支，训练 B 后只评估 A，形成 A→B→A 复测；最后一次 A 不包含重训。若另外重训 A，则单独统计重新达标所需新样本，衡量恢复难度。至少三个训练 seed，按训练 seed 汇总；增加评估 seed 只能减少评测噪声。失败尝试、回退前检查点和回退后检查点均保留，分别作图，避免保护机制把原始遗忘隐藏起来。

### 学习率与实际更新量

建议先固定结构、课程、初始探索分布和样本预算，对 \(\alpha\in\{10^{-5},3\times10^{-5},10^{-4}\}\) 做独立学习率对照。这是候选网格，不是预先认定的最优值。公平性需要同时记录 Adam 是否跨阶段重置、PPO epochs、minibatch 数、梯度裁剪、KL 门限及实际更新次数；不同训练配方不能仅按网络名字合并。

除新技能达标样本数和旧技能保持率，还记录：

\[
U_{\rm step}=\frac{\sum\texttt{optimizer\_steps}}
{\sum\texttt{planned\_optimizer\_steps}},\qquad
U_{\rm sample}=\frac{\sum\texttt{sample\_count}}
{E\sum\texttt{batch\_samples}},
\]

其中 \(E\) 是计划优化轮数。`sample_count` 是实际进入梯度更新的 endpoint 使用次数，重复使用同一个 rollout 样本会重复计数，不能当作新增环境样本。比较同时报告完整 rollout 样本、部分 rollout 样本和实际优化量；相同更新次数不保证相同计算量。

KL 衡量同一批状态上新旧动作分布的变化，局部近似可写为

\[
D_{\mathrm{KL}}(\pi_\theta\Vert\pi_{\theta+\Delta\theta})
\approx \tfrac12\Delta\theta^\top\mathcal F(\theta)\Delta\theta.
\]

学习率与网络几何、Adam 状态和梯度共同决定策略变化。因此既看设定的 \(\alpha\)，也看 `first_step_kl`、`final_kl`、动作均值变化、`clip_fraction`、梯度范数和 KL 提前停止比例。频繁提前停止是优化敏感性的线索，不能单独证明遗忘或证明学习率一定过大。最终 KL 也不必严格小于停止门限：检查发生在下一次优化步之前。[PPO 原论文](https://arxiv.org/abs/1707.06347)

学习率对照采用两层判断：共同配方用于观察结构在相同条件下的差异；候选各自调优用于比较最终可达到的控制表现。分别展示，避免把某一种结构的优化困难等同于结构上限。

### “记忆率”的三个明确含义

1. **旧技能保持率**：上面的 \(R_t\)，是评测结果。
2. **历史信息利用程度**：保持当前观测不变，只改变更早历史，观察动作和闭环控制变化。
3. **保持训练强度**：旧技能保持损失的权重、旧技能样本采样比例，是训练设置。

这三者不使用同一个百分比。门控残差中的门沿网络深度调节更新，不能当作时间上的遗忘率；注意力权重也不能直接当作历史信息带来的控制收益。GTrXL 的结果支持研究门控与优化稳定性的动机，仍需通过自己的固定窗口控制实验验证。[GTrXL 原论文](https://proceedings.mlr.press/v119/parisotto20a.html)

给历史输入 \(H_t\) 定义 \(T_h\)：保留最近 \(h\) 帧，其余槽位用最早保留帧填充，保持总槽位数、位置编码与当前帧不变。按各动作范围 \(D_a\) 归一化，动作依赖强度为

\[
U_h=\mathbb E\left[\left\|D_a^{-1}
\bigl(\mu_\theta(H_t)-\mu_\theta(T_hH_t)\bigr)\right\|_2^2\right].
\]

\(U_h\) 大只说明动作依赖历史，不能说明这种依赖有益。历史利用诊断排除 reset 后尚未形成真实窗口的至少 \(H-1\) 步，人工 repeat-first 槽位不计作真实记忆。分别做完整历史与截断历史的闭环测试，对每项代价 \(L\) 报告

\[
B_h=L_{\mathrm{truncated},h}-L_{\mathrm{full}}.
\]

\(L\) 分别取跟踪 RMSE、启停 IAE、恢复时间、力矩变化或失败率；不同量纲不直接相加。\(B_h>0\) 才表示完整历史在该指标上有收益。仅在完整历史相比当前帧基线有明确正收益时，可定义保留收益比例

\[
R_h=\frac{q_h-q_{\mathrm{current}}}{q_{\mathrm{full}}-q_{\mathrm{current}}}.
\]

分母接近零或非正时不适用；保留负值和大于 1 的值，不强行裁到百分比范围。测试时截断可能产生训练分布外输入，须结合不同历史长度重新训练的对照，才能判断最优记忆时域。

PPO 的折扣 \(\gamma\) 与 GAE 参数 \(\lambda_{\mathrm{GAE}}\) 控制信用分配，并不是网络存储记忆的比例。指数衰减时间尺度为

\[
\tau_\gamma=-\frac{\Delta t}{\ln\gamma},\qquad
\tau_{\mathrm{GAE}}=-\frac{\Delta t}{\ln(\gamma\lambda_{\mathrm{GAE}})}.
\]

例如 \(\Delta t=0.01\,\mathrm{s}\)、\(\gamma=\sqrt{0.99}\)、\(\lambda_{\mathrm{GAE}}=\sqrt{0.95}\) 时，两者约为 1.99 s 和 0.326 s；它们与 0.30 s 输入历史是三个不同的量。调整折扣/GAE 会改变学习目标和信用分配，应放在独立实验中。

旧技能锚点采用单独的教师保持项：

\[
\mathcal L=\mathcal L_{\mathrm{PPO}}+
\beta\,\mathbb E_{H\sim\mathcal A}
D_{\mathrm{KL}}\!\left(\pi_{\mathrm{teacher}}(\cdot\mid H)
\Vert\pi_\theta(\cdot\mid H)\right).
\]

\(\beta\) 是保持权重，不是保留率。旧锚点用于该保持项，不能混入当前 on-policy PPO rollout，冒充新采样。增加保持权重可能改善旧技能，也可能限制新技能适应；应画新技能改善与旧技能退步的权衡，而不是只优化一个数。锚点应来自合格教师，并按技能覆盖均衡抽样。[Policy Distillation 原论文](https://arxiv.org/abs/1511.06295)

### 记忆容量与部署成本

| 容量 | 含义 | 单独对照 |
|---|---|---|
| 历史长度与时域 | \(H\) 帧，\(\tau=(H-1)\Delta_h\) | 100 Hz 下 \(H=1,11,31,61\)，对应 0、0.10、0.30、0.60 s |
| 时间分辨率 | 历史采样间隔 \(\Delta_h\) | 固定 token 数比较时间跨度；固定跨度比较采样密度 |
| 表征容量 | \(d_{\mathrm{model}}\)、历史 latent、FFN 与层数 | 固定历史、层数、head 和 Actor head，分别扫宽度或 latent |
| 旧技能资料容量 | 每技能锚点数 \(K\) 与技能覆盖 | 例如 \(K=256,1024,4096\)，固定保持权重与抽样 batch |
| 运行成本 | 参数、激活、历史缓存、吞吐、CPU 推理 | 统一部署 PC，报告 p99、最大耗时和 10 ms 周期超时次数 |

不同历史长度的训练对照应固定相同年龄的帧位置编码：当前帧坐标为 0，过去帧按负 lag 编码。若随 \(H\) 改变当前帧的索引，则实验同时改变了长度和位置表示，不能只归因历史容量。多 stride 对照还须保持采集、reset 和部署一致，并评估稀疏采样的混叠。

标准 Transformer block 的主要计算量近似为

\[
\operatorname{MAC}\approx4Hd^2+2Hdf+2H^2d,
\]

其中 \(d\) 是模型宽度，\(f\) 是 FFN 宽度。窗口变长主要增加计算与激活，固定编码架构的参数量基本不随 \(H\) 变化；历史 MLP 第一层参数约为 \(35H\times w\)，会随长度增加。网络参数量、可见时间跨度与可保持技能数量不等价。

31×35 的 float32 原始历史约 4340 B/环境。保存历史加 6D 教师均值和 6D 标准差的锚点约 4388 B/条，2048 条约 8.57 MiB/文件，不含序列化开销。锚点容量扩大优先改善不同指令、转场与边缘状态覆盖，重复近似窗口未必改善保持能力。注意锚点池不进入部署端历史缓存。

### 分层实验与数据解释

先得到合格旧技能检查点，再进行学习率对照；从稳定候选中分别做历史容量和表征容量对照；最后从同一旧技能检查点分支比较保持权重及锚点容量。所有最终候选至少三个训练 seed。最后用小范围交叉实验验证学习率、容量与保持权重之间的交互，避免一次改变所有维度后无法归因。

阶段报告分别绘制：技能保持矩阵；新技能达标样本数与旧技能保持率；历史时域与跟踪、恢复、力矩及推理成本；保持权重与锚点容量的适应—保持权衡。没有已掌握旧技能的前后独立复测时，不输出遗忘率；只有单一学习率时，不输出最优学习率结论。若同一阶段中的任务分布变化，且已有合格旧技能参考和后续复测，也可以研究阶段内遗忘，不要求必须更换课程编号。

只读分析入口：

```bash
python tools/analyze_frame_learning.py \
  --study-root STUDY_OR_FROZEN_SNAPSHOT --output ANALYSIS.json \
  --first-update 101 --last-update 120
```

工具核验计划与配置来源，按完整 rollout 的共同窗口汇总实际优化量，并记录被排除的部分 rollout、续训边界和数据来源 SHA。输出用于优化诊断；没有独立旧技能跨课程评测时，遗忘和技能保持率标为不可确定。

## V6 物理响应与 sim2real 对照

新的 `prepare-transfer` 从已物化的 V6 平地训练合同准备独立研究任务，保留已辨识的两轮附加惯量、库仑阻力和粘滞阻力，校验资产、气簧及所有显式依赖 SHA。父合同为 50 Hz 策略、200 Hz 物理与新反馈 PD；研究统一为 100 Hz 策略、200 Hz 物理与 PD。它不宣称已经证明与真实 1 kHz 控制等价，也不把此前 100 Hz/1 kHz 名义动力学筛选与本轮混为同一实验。

十种候选仍限于单帧 MLP、历史 MLP 和 Transformer。共同使用 35D 公开观测、81D 特权 critic、31 帧历史模型的 0.30 s 窗口。首轮每种从头训练 1200 次更新，1024 环境、48 步 rollout，计划 58,982,400 条环境样本；一个训练 seed 用于筛选，正式选型仍需至少三个独立训练 seed。LR=3e-5、目标 KL=.01、初始动作均值缩放与标准差均为 1。实际优化步、KL 早停和实际环境样本一起报告。

保留 V6 的质量/COM、接触、观测噪声、执行强度和异步信号延迟机制。延迟人口为 75%；四组传感器和两组目标的年龄分别采样，观测最长 80 ms、目标最长 60 ms，本地 PD 使用新反馈。研究延迟渐入明确使用自身的第 200–600 次 Actor 更新，与父 V6 的 1500–2500 时钟不同，不继承旧模型的 13,000 次进度。噪声的配置人口与接触人口相交，有效人口期望约 25%；TensorBoard 的 `environment/` 标签记录实际人口、延迟强度和各组年龄，不仅记录配置开关。

固定评估使用六种基础任务：站立、前进、后退、旋转、启停和换高。每种任务有名义、20/15 ms、40/30 ms、80/60 ms 观测/目标年龄、噪声、载荷/COM、低摩擦和组合八种条件；再加入站立的电机和气簧弱化单因素，共 50 个用例。固定年龄按 5 ms 物理时钟表达，不将亚物理步延迟写成精确测量。组合条件不是实物不确定度的实测分布。

逐场景回读质量、COM、接触摩擦、信号年龄、噪声开关、执行强度和下行传输参数。评估的延迟模块强制使用完整课程强度；检查点缺省进度为零不能把延迟悄悄清掉。每次 reset 后恢复固定条件和清除噪声缓存。名义条件也显式关闭这些额外扰动，不因模块存在而误称已施加随机化。
