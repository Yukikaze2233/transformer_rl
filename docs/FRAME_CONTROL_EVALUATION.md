# 网络结构的闭环运动控制评估

模型选型先检查任务是否达标，再比较动态响应、执行器负担和实时开销。训练 reward 与普通持续任务的存活率不能替代指令跟踪成绩。本协议独立于训练计划，使用相同冻结检查点、场景和评估 seed 比较单帧 MLP、历史 MLP 与 Transformer。

## 评估信号与口径

`--control-output` 启用额外的 PRE-reset 物理诊断，默认不影响既有训练与评估。按场景分别输出：

- 高度、前向速度和偏航角速度误差：bias、MAE、RMSE、峰值、误差带内样本和时间比例、全区间 IAE。稳态按每个环境的每个固定指令保持段去均值，同时保留各段均值差异。
- reset 与指令切换分别计数。失败和短回合计入全区间统计；稳态样本不足时明确标记，不能以丢弃短失败回合得到的低波动作为成功证据。
- 大幅有效指令切换：采样点上的 10%–90% 上升时间、绝对超调、进入容差并连续保持 0.5 s 的调节时间。初始指令未跟踪、保持时间过短、终止或未到达目标分别标记；无法确定的指标为 null。持续小幅 slew 不冒充阶跃。
- 腿目标变化率 rad/s、轮速目标加速度 rad/s²、连续腿关节最短角差、轮速目标到实际速度的误差、实际力矩 RMS/峰值与变化率、请求力矩超限和实际力矩到界比例。
- 采样点上的绝对机械功率 \(\sum_j|\tau_j\dot q_j|\)，不称为电耗或高频电流纹波。实际力矩与请求力矩分别记录。

初筛误差带沿用现有场景：速度 0.15 m/s、偏航速度 0.25 rad/s、高度 0.03 m。它们是仿真初筛参数，不是硬件验收标准。每段保留充分样本后再比较波动；跨 reset 不作差分或误差积分。位移只有在静止指令下解释为漂移。

## 原始轨迹

`--trace-output` 保存可复查 NPZ，默认按每个场景预先选定前两个副本，不按成败选择轨迹。完整场景统计仍使用全部环境。数组包括有效指令、实际响应、目标与实际执行器量、时间、done 和 episode_id；元数据保存检查点 SHA、seed、观测/动作合同与采样频率。

轨迹使用磁盘映射写入，内存不随评测时长增长；完整成功后发布最终文件，失败保留日志而不发布完整轨迹。100 Hz 轨迹只覆盖策略采样频段，不能代表 1000 Hz 物理子步的全部峰值。没有可靠的请求时间戳时不报告传输时延。

```bash
python -m transformer_rl.frame_process evaluate-suite \
  --checkpoint CHECKPOINT --configs CASE_CONFIGS --outputs CASE_REPORTS \
  --steps 4001 --seed 5701 --device cuda:0 \
  --control-output OUTPUT/control.json --trace-output OUTPUT/trace.npz
```

## 独立补充评测调度

```bash
python tools/run_frame_control_campaign.py \
  --study-root STUDY --output-root OUTPUT --source-root SOURCE \
  --updates 200 --seeds 5701 6701 --steps 4001 --device cuda:0
```

调度器核验原计划、配置、训练完成回执与检查点 SHA；等待原执行器释放锁并确认原 worker 已结束，然后串行评测全部十种候选。原任务门槛不通过的模型仍保留在补充评测中；未到预算的模型明确列为未就绪。每次失败后创建新 attempt，完整产物不覆盖。新增评估 seed 与原训练、验证、锚点和最终测试 seed 分开；新增结果用于补充验证，不冒充未接触过的最终留出测试。

`campaign.json` 固定源代码、场景、预算和 seed；`summary.json` 记录运行状态及所有候选；每个 attempt 保存命令、进程身份、场景报告、control.json、trace.npz 和 SHA 回执。统计按场景、评估 seed、训练 seed 分层汇总，不能把帧数当作独立训练 seed 数。

先完成相同预算的固定场景评估，依据任务达标与控制指标筛选候选，再对合格候选执行抗扰、时延扫描、历史长度消融与跨课程技能保持验证。额外实验需要冻结各自场景协议和来源；本套件不将它们标作已经完成。
