# 通用策略网络综述配图

用于[策略网络结构比较](../../NETWORK_COMPARISON.md)，不绑定观测维度、仓库配置或实测结果。

- `families.svg/png`：五种时间信息处理方式。
- `timing.svg/png`：历史跨度、计算方式与完整控制链路。表内数值仅为时间窗口换算示例。

运行 `python render.py` 可重新生成SVG及2倍分辨率PNG，需要Python、`rsvg-convert`、Noto Sans CJK SC和Times New Roman字体。数学变量斜体，数字及运算符正体；中文使用黑体。上传文档使用PNG，以保留字体和上下标排版。
